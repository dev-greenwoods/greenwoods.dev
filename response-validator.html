What this tool does

Check generated JSON against a schema and show exact failing paths. Supports common types, required properties, enums, constants, arrays, and basic bounds.

Privacy and limits

Validation runs locally. This lightweight validator covers common JSON Schema keywords; it does not fetch remote references or execute schema code.
