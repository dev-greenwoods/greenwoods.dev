TASK GUIDE · OUTPUT VALIDATION

How to validate LLM output

Define the output contract before reviewing generated responses. Local checks catch malformed or structurally invalid data, but cannot prove semantic correctness.

1 Define the expected shape

Build a schema with the Structured Output Builder and check a sample using the LLM Response Validator.

2 Validate the response contract

Use the Response Contract Tester to test required paths, types, allowed values, and forbidden fields.

3 Cover representative cases

Compare expected and actual outputs with the LLM Eval Harness. Include empty, boundary, malformed, and adversarial examples relevant to your application.

Treat validation as one layer of defense; validate again in your application before trusting model output.
