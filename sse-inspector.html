What this tool does
Parse event-stream boundaries, preserve event names and IDs, reconstruct common OpenAI, Anthropic, and Gemini text deltas, and show per-event timing gaps when supplied.
Timing limits
Plain SSE has no standard receive timestamps. This inspector reports gaps only for explicit timestamps in event comments or JSON fields; it does not invent timing data.
