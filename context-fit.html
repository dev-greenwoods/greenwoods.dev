What this tool does
Inspect a messages array, estimate token usage per message, and preview a context-safe selection that preserves the system message and newest messages.
Estimates are approximate
Counts reuse the Token Counter's local approximation and exclude provider-specific message overhead. Exact counts vary by model and message format.
