What this tool does
Format role-prefixed chat transcripts or JSONL records as OpenAI chat fine-tuning examples. Common role aliases are normalized and duplicate valid examples are removed.
Validation
Each record must contain non-empty user and assistant messages. Bad lines are reported instead of silently included. Files are read locally and never uploaded.
